## Requirements

- Python 3.12+
- Docker (optional)
- Optional local MQTT broker for live experiments

## Run locally

```bash
python -m venv .venv
.venv/Scripts/activate
pip install -e ".[dev]"
set PYTHONPATH=src
uvicorn app:app --app-dir src --reload --port 8080
```

Health check:

```bash
curl http://localhost:8080/health
```

Expected without a broker:

```json
{
  "status": "UP",
  "service": "${{ values.name }}",
  "version": "${{ values.version }}",
  "mqttEnabled": false,
  "mqttConnected": false
}
```
