# Create

Created from Marketplace → **OEE Data Product**. Fields: Name, Description,
Owner, System, Domain, Site, Area, Line, Equipment Identifier, Default Window
(`HOUR` / `SHIFT` / `ORDER` / `CUSTOM`), MQTT machine-state topic, MQTT
counter topic, Production Context URL Reference, GitHub repository.

The wizard does not ask you to design OEE formulas. Microstop thresholds,
Pareto, MTBF, reason hierarchy, and SMED are not Create options.

Do not paste tokens or passwords into Create. Put secrets in runtime `.env`.
