# UNS Governance

Owner: Platform Team  
Last reviewed: 2026-08-20  
Audience: PLATFORM USER  
Version: 1.0.0

UNS uses existing platform governance:

- Data Contracts as Catalog API entities
- Quality status on topic metadata (`DEVELOPMENT` for samples)
- Compatibility and versioning of contract `x.y.z` versions
- Catalog ownership (`group:default/platform-team` by default)

This is technical platform governance. It is not a GxP validation claim.
