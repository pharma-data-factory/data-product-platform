# Upgrade Guide

Owner: Platform Team  
Documentation Version: 1.0  
Applicable Platform: Data Product Standard 1.0.x  
Last Reviewed: 2026-08  
Audience: PLATFORM USER

Upgrade Status compares a generated Data Product with the current
RELEASED Golden Path version. The platform does not change repositories
automatically. Detection only.

Example:

- Product generated with MQTT Template 1.0.0
- Current RELEASED MQTT Template 1.2.0
- Result: UPDATE_AVAILABLE

Statuses: CURRENT, UPDATE_AVAILABLE, UPGRADE_REQUIRED, UNSUPPORTED.

Canonical policy: [versioning-policy.md](../versioning-policy.md) and
[versioning.md](versioning.md).
