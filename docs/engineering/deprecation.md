# Golden Path deprecation

Owner: Platform Team  
Documentation Version: 1.0  
Applicable Platform: Data Product Standard 1.0.x  
Last Reviewed: 2026-08  
Audience: PLATFORM USER

DEPRECATED releases stay in the Release Catalog. They are not deleted.

Required metadata:

- replacementVersion
- deprecationDate
- supportUntil
- migrationGuide

RETIRED releases must not be offered for new Data Product creation.
Existing generated Data Products remain visible in Catalog.

Developers create from the current RELEASED version only.

Related: [Upgrade Guide](upgrade-guide.md), [Lifecycle](golden-path-lifecycle.md).
