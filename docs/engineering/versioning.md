# Versioning and upgrades

Owner: Platform Team  
Last reviewed: 2026-08-19  
Audience: PLATFORM USER  
Version: MVP 1.1

Canonical policy: [versioning-policy.md](../versioning-policy.md).
Golden Path releases: [Release management](release-management.md) and
[Upgrade Guide](upgrade-guide.md). Platform Components use the same
SemVer rules: [Component versioning](../platform-components/versioning.md).

Upgrade Status on a Data Product compares reported standard, SDK, and
template versions with the current RELEASED Golden Path line. The platform does not change
repositories automatically.

| Status | Meaning |
| --- | --- |
| CURRENT | Matches the supported line |
| UPDATE_AVAILABLE | Compatible newer line exists |
| UPGRADE_REQUIRED | Drift that should be planned |
| UNSUPPORTED | Outside the supported matrix |

MVP 1.0 baseline: [mvp-1.0-baseline.md](../mvp-1.0-baseline.md).
