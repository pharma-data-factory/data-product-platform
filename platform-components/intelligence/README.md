# Intelligence Components

Planned Platform Components for future RAG, LLM, and Knowledge Graph
compositions. Catalog entities are registered with certification status
PLANNED. Do not implement AI provider integrations, RAG runtimes, or
graph stores in this phase.

Composition sketch:

Document Loader → Chunker → Embeddings → Vector Store → Retriever → LLM Gateway

Knowledge Graph is documented separately. GraphRAG is Documented as
Knowledge Graph + Vector Retrieval + LLM Gateway.
